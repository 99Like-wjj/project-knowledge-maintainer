# 完全合成示例

knowledge.synthetic 是符合格式v3 的四类纯虚构项目知识（结构化地图/规则、用户提供的轻量项目/账号记录）；common-materials.synthetic.md 是通用规则筛选的纯虚构原始资料，混有应留在原文的功能细则。工程夹具和联通测试使用这些内容，实际结果见[开发自测](../docs/development-validation.md)。

后续仅允许添加**完全合成**、明确标记为虚构的示例，用于验证跨项目隔离、创建、增量维护和使用方读取。示例不得来自真实业务资料、真实知识库或真实测试证据；不要自行以“脱敏”替代来源审查。

真实项目的输入、知识产物、测试数据、报告、日志、截图与凭据均不得放入此目录或仓库其他位置。具体规则见 [AGENTS.md](../AGENTS.md)。
