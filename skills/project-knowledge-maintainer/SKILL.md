# 项目知识创建与维护

AI负责资料理解、知识提炼和业务判断，工具负责文件、结构、引用和版本事务。当前正式版本为0.1.0，知识格式v3。

## 选择内容

功能地图保留模块用途、所属应用/页面和模块级入口；通用规则保留跨功能的业务约束、角色允许/禁止、范围及例外。字段校验、单功能特殊分支、完整流程和用例仍查原需求，不录按钮脚本。知识的来源、适用范围和确认状态分开表达。

账号配置和项目配置默认只整理用户提供的内容：用户用自然语言、表格或已有说明给信息，AI忠实登记，不要求用户填写JSON。每条仅需id/title，标识由AI生成；摘要、标签、文字说明与自定义properties均可选。不要求先建角色、组织、环境或页面表，不因字段未填齐生成全项目准备清单。用户另行要求分析测试需要哪些身份时再做准备建议，不能把建议画像登记成真实账号。

## 位置与初始化

只使用本次授权资料及明确目标路径。真实原始资料、知识、草案、运行产物和账号留在用户确认的库外私有目录；不得进入本Skill或Ego源码/安装目录，私有仓库也不例外。示例只能完全合成。

先读[格式与工具](references/format-and-tools.md)。初始化只生成身份和空project.json，不造账号、网址或缺项问题。重复初始化保留身份、创建时间和已有文件；错项目、旧格式、损坏库及未知非空目录不通过重建覆盖。用户要求先审候选时，审核前不加入正式规则。

## 整理与维护

规则、导航及历史观察保留确定来源和业务边界；未确认为pending，实际现象为observed，有明确依据才可为confirmed，一次现象不能倒推正确规则。appliesTo用自然语言说明适用范围；没有说明表示未知，不表示全环境适用。地图直接写应用/页面和模块路径，不依赖project配置。

配置按用户原意保留自有字段，不强制套知识确认状态或来源档案。可以忠实生成用途摘要和标签以便检索，账号摘要不抄登录标识。账号实际权限、登录就绪和本轮操作授权仍须具体任务核对；不存密码、Token、Cookie或一次性登录链接，不解析逻辑凭据引用。

维护时核对实际基线和影响。规则、来源、历史观察保留原保留约束；账号/项目配置可按用户明确指令修正或移除，文件前版经Git或外部备份保存。三方差异只列双方改动与冲突候选，AI结合来源判定，不按最后时间戳、ours/theirs自动覆盖。

## 工具与交付

完整安装包的CLI为本Skill根目录下runtime/src/cli.mjs，安装方法见[安装说明](INSTALL.md)。开发时在已确认源码仓库运行npm run build，CLI为该仓库的.build/src/cli.mjs；源码Skill子目录不是完整安装包，不自动更换已安装版本。工具接收显式路径和AI准备的内容，不调用模型或扫描业务系统。

validate检查当前文件；save使用expectedSnapshotSha256。覆盖未由干净Git保存的旧文件需给库外backupDir。中断先recover查看，再按精确transactionId完成prepared文件事务；外部改动不无条件覆盖，恢复不等于重放业务操作。

提交、同步和发布按本次授权逐文件审查，忽略规则不代替保密检查；只按明确路径暂存，不使用全量git add或commit -a。交付实际位置、变化、来源及本任务相关缺项，不把文件保存当业务验证。Ego等使用方直接按同一规范读取，本Skill不提供运行时测试查询服务。
