# 项目知识库创建与维护（草案）

**当前仅为入口占位，不是可执行 Skill。不要据此声称已具备创建、维护、校验或安装能力。**

## 计划用途

从用户授权提供的资料创建独立项目知识库，并在资料变化后增量维护来源、关系、冲突及待确认信息。能力应可跨项目复用，不绑定特定业务系统。

## 使用边界

- 本 Skill 负责创建与维护；Ego Lite 等使用方自行读取、查询和使用产物。
- 真实资料和生成知识必须存放于仓库外，不得提交或上传；先阅读根目录的 [AGENTS.md](../../AGENTS.md)。
- 不凭空补齐事实，不将一次观察视为正式规则，不以知识描述替代操作授权。
- 当前没有完整执行步骤、输入输出协议或错误处理实现。正式设计前，不将此草案作为生产工作流执行。

后续开发依据：[范围与开发交接](../../docs/scope.md)、[数据约定讨论稿](../../docs/data-contract-draft.md)。
