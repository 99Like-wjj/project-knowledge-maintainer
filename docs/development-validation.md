## 实现与边界

AI 从资料选择项目内跨功能复用的规则与准备知识，工具提供初始化、校验、带前版保护的增量保存、prepared 事务核对恢复及本地 Git 三方差异。功能仅保留必要的短索引；字段校验、页面细节和单功能分支保留原需求，不逐项生成知识缺口。

初始化允许无资料、无 scope 的有效空库；重复调用保留 ID、创建时间和已有字节。保存检查当前指纹，旧条目/陈述以状态保留，旧来源 ID 不改指新版。未由干净 Git 保留的覆盖内容必须在显式外部目录保存原字节。保存中断不自动重放业务操作，也不覆盖后续外部编辑。

维护端不承担测试运行时查询。Ego 自带查询实现并携带相同 contract/store/schema 的内容副本；本次逐文件核对两仓库字节与记录 SHA 一致，数据规范与源代码版本分别管理。
